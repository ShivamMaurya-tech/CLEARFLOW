--------ClearFlow — Product Landing Page

A clean, modern, single-file SaaS landing page built for ClearFlow—designed to showcase a clear, fast, and affordable unified workflow solution to potential customers with interactive elements, visual explainers, transparent pricing, and direct booking/contact flows.

---

-- Key Features

Zero-Build, Single-File Architecture: Everything (HTML, Tailwind CSS styling, custom inline SVGs, and vanilla JavaScript interactivity) is contained in a single index.html file—no build tools or dependencies required.

Sticky Responsive Navigation: Includes smooth anchor scrolling, brand logo, desktop CTA, and an accessible mobile dropdown menu.

Upfront UVP & Interactive Before/After Preview: Visitors can toggle live between Before: Scattered Tools and After: ClearFlow to immediately visualize the product's value proposition.

3-Step Visual Infographic Explainer: Custom lightweight inline SVG diagrams illustrating workflow consolidation, transparent pricing, and automated tracking with human support.

Live Time & Cost Savings Estimator: Interactive range sliders calculate estimated monthly hours reclaimed, dollar value saved, and annual savings in real time.

Key Features & Early User Impact: Highlights the 4 core product benefits alongside outcome-driven early adopter testimonials and metrics.

Transparent Pricing Toggle: Two clean pricing plans (Starter and Growth) with a live Monthly / Annual (Save 20%) billing switch.

Direct Contact & Call Request Form: Features one-click email copying (hello@clearflow.app), quick-fill bottleneck tags, client-side validation, and instant confirmation feedback.

Interactive 10-Min Walkthrough Modal: Dynamically generates the next 4 upcoming weekdays and time slots, lets visitors pick a slot, and displays an instant booking confirmation.

🛠️ Tech Stack

HTML5 — Semantic, accessible structure

Tailwind CSS (CDN) — Utility-first responsive styling

Google Fonts (Inter) — Crisp modern typography

Vanilla JavaScript — Zero external JS libraries; handles all modals, toggles, calculators, and forms

Inline SVGs — Crisp, scalable icons and infographics with zero broken image links
